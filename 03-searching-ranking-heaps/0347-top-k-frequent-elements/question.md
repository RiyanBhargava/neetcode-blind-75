## Problem brief

Return the `k` distinct values that occur most often in the input. The answer may be returned in any order.

## Example

`nums = [1,1,1,2,2,3]`, `k = 2` → `[1,2]`

## Constraints

`1 <= len(nums) <= 10^5`; `k` does not exceed the number of distinct values; the answer is unique.
