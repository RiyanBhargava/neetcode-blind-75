# 269. Alien Dictionary

**Category:** Advanced Graphs  
**Difficulty:** Hard

[NeetCode problem](https://neetcode.io/problems/foreign-dictionary/) | [LeetCode problem](https://leetcode.com/problems/alien-dictionary/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

A list of words is already sorted using an unknown alphabet. Return a string ordering every distinct character in a way consistent with that list. Return an empty string if no ordering exists; if several exist, any valid ordering is acceptable. A shorter word precedes its longer extension.

## Example

```text
words = ["z", "x"] -> "zx"; words = ["abc", "ab"] -> ""
```
