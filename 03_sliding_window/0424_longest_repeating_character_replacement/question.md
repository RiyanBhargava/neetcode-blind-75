# 424. Longest Repeating Character Replacement

**Category:** Sliding Window  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/longest-repeating-substring-with-replacement/) | [LeetCode problem](https://leetcode.com/problems/longest-repeating-character-replacement/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given an uppercase English string and an integer k, you may change at most k characters into any uppercase letter. Return the longest contiguous substring that can consist of a single repeated letter after those changes.

## Example

```text
s = "ABAB", k = 2 -> 4
```
