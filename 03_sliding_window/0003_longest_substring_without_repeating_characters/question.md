# 3. Longest Substring Without Repeating Characters

**Category:** Sliding Window  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/longest-substring-without-duplicates/) | [LeetCode problem](https://leetcode.com/problems/longest-substring-without-repeating-characters/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Return the length of the longest contiguous substring containing no repeated character. Treat spaces, punctuation, and letters as characters; an empty string has length zero.

## Example

```text
s = "dvdf" -> 3
```
