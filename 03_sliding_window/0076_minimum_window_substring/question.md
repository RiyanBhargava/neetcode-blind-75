# 76. Minimum Window Substring

**Category:** Sliding Window  
**Difficulty:** Hard

[NeetCode problem](https://neetcode.io/problems/minimum-window-with-characters/) | [LeetCode problem](https://leetcode.com/problems/minimum-window-substring/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given strings s and t, return the shortest contiguous substring of s containing every character of t, including repeated occurrences. Return an empty string if none exists. The shortest answer is unique when it exists. Follow-up: target O(len(s) + len(t)) time.

## Example

```text
s = "aaabcbc", t = "abc" -> "abc"
```
