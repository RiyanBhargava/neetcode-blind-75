# 121. Best Time to Buy And Sell Stock

**Category:** Sliding Window  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/buy-and-sell-crypto/) | [LeetCode problem](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given daily stock prices, find the greatest profit from buying once and selling on a later day. Return zero if no profitable transaction exists.

## Example

```text
prices = [9, 3, 6, 1, 5] -> 4
```
