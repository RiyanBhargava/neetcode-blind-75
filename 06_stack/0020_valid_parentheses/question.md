# 20. Valid Parentheses

**Category:** Stack  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/validate-parentheses/) | [LeetCode problem](https://leetcode.com/problems/valid-parentheses/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given a string containing only parentheses, square brackets, and braces, determine whether all brackets are correctly matched and nested. Each closing bracket must match the most recent unmatched opening bracket of the same type.

## Example

```text
s = "{[()]}" -> true; s = "([)]" -> false
```
