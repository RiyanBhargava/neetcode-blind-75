# 338. Counting Bits

**Category:** Bit Manipulation  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/counting-bits/) | [LeetCode problem](https://leetcode.com/problems/counting-bits/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

For a nonnegative integer n, return an array of length n + 1 whose element at index i counts the set bits in i. Follow-up: compute the full array in O(n) time without a built-in bit-count operation.

## Example

```text
n = 5 -> [0, 1, 1, 2, 1, 2]
```
