# 191. Number of 1 Bits

**Category:** Bit Manipulation

## Task

Return the number of set bits in the 32-bit binary representation of a nonnegative integer n. Follow-up: consider how to handle many calls efficiently.

## Example

```text
n = 13 (binary 1101) -> 3
```
