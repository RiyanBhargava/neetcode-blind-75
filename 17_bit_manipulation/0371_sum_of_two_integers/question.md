# 371. Sum of Two Integers

**Category:** Bit Manipulation  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/sum-of-two-integers/) | [LeetCode problem](https://leetcode.com/problems/sum-of-two-integers/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given signed integers a and b, return their sum without using the addition or subtraction operators. Account for negative values as well as positive values.

## Example

```text
a = -4, b = 7 -> 3
```
