# 190. Reverse Bits

**Category:** Bit Manipulation  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/reverse-bits/) | [LeetCode problem](https://leetcode.com/problems/reverse-bits/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Reverse the order of all 32 bits in an unsigned integer and return the unsigned integer represented by the reversed bits. Leading zeros are part of the 32-bit input.

## Example

```text
n = 1 -> 2147483648
```
