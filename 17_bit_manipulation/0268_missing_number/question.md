# 268. Missing Number

**Category:** Bit Manipulation  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/missing-number/) | [LeetCode problem](https://leetcode.com/problems/missing-number/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

An array of length n contains distinct integers drawn from 0 through n, with exactly one number missing. Return the missing value. Follow-up: use O(n) time and constant extra space.

## Example

```text
nums = [4, 0, 1, 3] -> 2
```
