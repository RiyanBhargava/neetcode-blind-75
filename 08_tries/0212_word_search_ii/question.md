# 212. Word Search II

**Category:** Tries  
**Difficulty:** Hard

[NeetCode problem](https://neetcode.io/problems/search-for-word-ii/) | [LeetCode problem](https://leetcode.com/problems/word-search-ii/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given a rectangular letter grid and a list of distinct words, return every listed word that can be traced through horizontal or vertical neighbors. A cell may not repeat within one word path. Return each matching word once in any order.

## Example

```text
board = [["a", "b"], ["c", "d"]], words = ["abd", "ac", "ad"] -> ["abd", "ac"]
```
