# 208. Implement Trie Prefix Tree

**Category:** Tries  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/implement-prefix-tree/) | [LeetCode problem](https://leetcode.com/problems/implement-trie-prefix-tree/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Implement a Trie for lowercase English words with insert(word), search(word), and startsWith(prefix). Search succeeds only for a complete inserted word; startsWith succeeds for any prefix of an inserted word.

## Example

```text
insert("cat"), search("ca") -> false; startsWith("ca") -> true
```
