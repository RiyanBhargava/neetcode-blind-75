# 211. Design Add And Search Words Data Structure

**Category:** Tries  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/design-word-search-data-structure/) | [LeetCode problem](https://leetcode.com/problems/design-add-and-search-words-data-structure/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Implement WordDictionary with addWord(word) and search(word). Stored words use lowercase English letters. A search pattern may also contain a dot, which matches exactly one arbitrary letter. Return whether any stored word matches the entire pattern.

## Example

```text
addWord("cat"), search("c.t") -> true; search("c..s") -> false
```
