# 125. Valid Palindrome

**Category:** Two Pointers  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/is-palindrome/) | [LeetCode problem](https://leetcode.com/problems/valid-palindrome/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Determine whether a string reads the same forward and backward after ignoring non-alphanumeric characters and letter case. A string with no remaining characters is a palindrome.

## Example

```text
s = "Was it a rat I saw?" -> true
```
