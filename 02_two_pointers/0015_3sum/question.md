# 15. 3Sum

**Category:** Two Pointers  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/three-integer-sum/) | [LeetCode problem](https://leetcode.com/problems/3sum/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Return all distinct value triplets from an integer array that sum to zero. Each triplet must use three different indices. Duplicate value triplets must appear only once; answer order does not matter.

## Example

```text
nums = [-2, 0, 1, 1, 2] -> [[-2, 0, 2], [-2, 1, 1]]
```
