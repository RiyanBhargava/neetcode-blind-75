# 1143. Longest Common Subsequence

**Category:** 2-D Dynamic Programming  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/longest-common-subsequence/) | [LeetCode problem](https://leetcode.com/problems/longest-common-subsequence/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given two strings, return the length of their longest common subsequence. A subsequence preserves character order but need not be contiguous. Return zero if the strings share no character.

## Example

```text
text1 = "abcde", text2 = "ace" -> 3
```
