# 62. Unique Paths

**Category:** 2-D Dynamic Programming  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/count-paths/) | [LeetCode problem](https://leetcode.com/problems/unique-paths/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Starting at the top-left cell of an m by n grid, count the distinct paths to the bottom-right cell when each move goes one cell right or down. The grid has no obstacles.

## Example

```text
m = 2, n = 4 -> 4
```
