# 143. Reorder List

**Category:** Linked List  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/reorder-linked-list/) | [LeetCode problem](https://leetcode.com/problems/reorder-list/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Reorder a singly linked list L0, L1, ..., Ln into L0, Ln, L1, Ln-1, and so on. Change node links in place; do not change node values.

## Example

```text
head = [1, 2, 3, 4, 5] -> [1, 5, 2, 4, 3]
```
