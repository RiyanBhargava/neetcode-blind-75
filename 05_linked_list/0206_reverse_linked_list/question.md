# 206. Reverse Linked List

**Category:** Linked List  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/reverse-a-linked-list/) | [LeetCode problem](https://leetcode.com/problems/reverse-linked-list/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Reverse a singly linked list and return its new head. An empty list remains empty. Follow-up: implement both an iterative and a recursive version.

## Example

```text
head = [2, 4, 7] -> [7, 4, 2]
```
