# 21. Merge Two Sorted Lists

**Category:** Linked List  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/merge-two-sorted-linked-lists/) | [LeetCode problem](https://leetcode.com/problems/merge-two-sorted-lists/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Merge two nondecreasing singly linked lists into one nondecreasing list by relinking their existing nodes. Return the merged head; either input may be empty.

## Example

```text
list1 = [1, 4], list2 = [2, 3, 5] -> [1, 2, 3, 4, 5]
```
