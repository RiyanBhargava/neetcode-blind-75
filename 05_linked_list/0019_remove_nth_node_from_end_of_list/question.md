# 19. Remove Nth Node From End of List

**Category:** Linked List  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/remove-node-from-end-of-linked-list/) | [LeetCode problem](https://leetcode.com/problems/remove-nth-node-from-end-of-list/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Remove the nth node counted from the end of a singly linked list and return its head. The value n is valid for the list length. Follow-up: accomplish this in one pass.

## Example

```text
head = [2, 4, 6, 8], n = 2 -> [2, 4, 8]
```
