# 23. Merge K Sorted Lists

**Category:** Linked List  
**Difficulty:** Hard

[NeetCode problem](https://neetcode.io/problems/merge-k-sorted-linked-lists/) | [LeetCode problem](https://leetcode.com/problems/merge-k-sorted-lists/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given k singly linked lists, each sorted in nondecreasing order, merge them into one sorted list and return its head. The collection and individual lists may be empty.

## Example

```text
lists = [[1, 5], [2, 4], [3]] -> [1, 2, 3, 4, 5]
```
