# 141. Linked List Cycle

**Category:** Linked List  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/linked-list-cycle-detection/) | [LeetCode problem](https://leetcode.com/problems/linked-list-cycle/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Determine whether following next pointers in a singly linked list eventually revisits a node. The judge may describe the cycle with a position, but that position is not a function argument. Follow-up: use constant additional memory.

## Example

```text
head = [5, 8, 2], tail points to index 1 -> true
```

This is an original concise restatement. Use the linked problem for the complete constraints and judge interface.
