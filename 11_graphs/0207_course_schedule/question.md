# 207. Course Schedule

**Category:** Graphs  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/course-schedule/) | [LeetCode problem](https://leetcode.com/problems/course-schedule/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Courses are numbered from 0 to numCourses - 1. A pair [a, b] means course b must be finished before course a. Determine whether it is possible to finish every course.

## Example

```text
numCourses = 3, prerequisites = [[1, 0], [2, 1]] -> true
```
