# 133. Clone Graph

**Category:** Graphs  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/clone-graph/) | [LeetCode problem](https://leetcode.com/problems/clone-graph/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Create a deep copy of a connected undirected graph given a reference to one node. Each node has a value and a list of neighbor references. Return the corresponding copied node, with no original nodes reused; a null input produces null.

## Example

```text
adjacency list = [[2], [1]] -> a separate graph with adjacency list [[2], [1]]
```
