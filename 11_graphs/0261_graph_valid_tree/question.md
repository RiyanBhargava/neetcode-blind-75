# 261. Graph Valid Tree

**Category:** Graphs  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/valid-tree/) | [LeetCode problem](https://leetcode.com/problems/graph-valid-tree/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given n vertices labeled 0 through n - 1 and undirected edges, determine whether the graph is a tree: all vertices must be connected, and no cycle may exist. Input edges have no self-loops or duplicates.

## Example

```text
n = 4, edges = [[0, 1], [1, 2], [1, 3]] -> true
```
