# 323. Number of Connected Components In An Undirected Graph

**Category:** Graphs  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/count-connected-components/) | [LeetCode problem](https://leetcode.com/problems/number-of-connected-components-in-an-undirected-graph/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given n vertices labeled 0 through n - 1 and a list of undirected edges, return the number of connected components. Count an isolated vertex as its own component.

## Example

```text
n = 5, edges = [[0, 1], [1, 2], [3, 4]] -> 2
```
