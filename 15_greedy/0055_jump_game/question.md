# 55. Jump Game

**Category:** Greedy  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/jump-game/) | [LeetCode problem](https://leetcode.com/problems/jump-game/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

You start at index zero of a nonempty array of nonnegative integers. Each value is the greatest number of positions you may jump forward from that index; shorter jumps are allowed. Determine whether you can reach the final index.

## Example

```text
nums = [2, 0, 1, 0] -> true
```
