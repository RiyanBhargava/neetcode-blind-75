# 53. Maximum Subarray

**Category:** Greedy  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/maximum-subarray/) | [LeetCode problem](https://leetcode.com/problems/maximum-subarray/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given a nonempty integer array, return the largest sum of any nonempty contiguous subarray. A subarray must contain consecutive elements.

## Example

```text
nums = [-4, 3, -1, 5, -6] -> 7
```
