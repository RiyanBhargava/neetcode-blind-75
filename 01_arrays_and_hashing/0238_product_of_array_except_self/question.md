# 238. Product of Array Except Self

**Category:** Arrays & Hashing  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/products-of-array-discluding-self/) | [LeetCode problem](https://leetcode.com/problems/product-of-array-except-self/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Return an array whose element at index i is the product of every input value except nums[i]. Do not use division, and use O(n) time. Products of prefixes and suffixes fit in a signed 32-bit integer. Follow-up: use constant extra space apart from the output.

## Example

```text
nums = [2, 3, 5] -> [15, 10, 6]
```
