# 49. Group Anagrams

**Category:** Arrays & Hashing  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/anagram-groups/) | [LeetCode problem](https://leetcode.com/problems/group-anagrams/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Group a list of lowercase English strings so that two strings belong to the same group exactly when they are anagrams. The order of groups and the order within each group do not matter.

## Example

```text
strs = ["ab", "ba", "cat", "act", "x"] -> [["ab", "ba"], ["cat", "act"], ["x"]]
```
