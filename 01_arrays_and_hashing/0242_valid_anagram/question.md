# 242. Valid Anagram

**Category:** Arrays & Hashing  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/is-anagram/) | [LeetCode problem](https://leetcode.com/problems/valid-anagram/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given two strings of lowercase English letters, determine whether one is a rearrangement of the other. Every character must occur the same number of times in both strings.

## Example

```text
s = "silent", t = "listen" -> true
```
