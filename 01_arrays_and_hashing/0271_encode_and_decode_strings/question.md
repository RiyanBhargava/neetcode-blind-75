# 271. Encode and Decode Strings

**Category:** Arrays & Hashing  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/string-encode-and-decode/) | [LeetCode problem](https://leetcode.com/problems/encode-and-decode-strings/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Implement encode(strs) and decode(s) to convert a list of strings into one string and recover the original list exactly. Handle empty strings, an empty list, and arbitrary characters without ambiguity; do not use built-in serialization.

## Example

```text
decode(encode(["", "a#b", "hello"])) -> ["", "a#b", "hello"]
```
