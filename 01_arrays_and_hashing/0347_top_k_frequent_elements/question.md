# 347. Top K Frequent Elements

**Category:** Arrays & Hashing  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/top-k-elements-in-list/) | [LeetCode problem](https://leetcode.com/problems/top-k-frequent-elements/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given an integer array nums and a valid integer k, return the k distinct values that occur most often. The answer is unique, and its order does not matter. Aim for better than O(n log n) time.

## Example

```text
nums = [4, 4, 4, 8, 8, 2], k = 2 -> [4, 8]
```
