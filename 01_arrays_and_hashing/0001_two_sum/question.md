# 1. Two Sum

**Category:** Arrays & Hashing  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/two-integer-sum/) | [LeetCode problem](https://leetcode.com/problems/two-sum/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given an integer array nums and an integer target, return the zero-based indices of two distinct elements whose sum is target. Exactly one pair exists; either index order is acceptable.

## Example

```text
nums = [4, 7, 2], target = 9 -> [1, 2]
```
