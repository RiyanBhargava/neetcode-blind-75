# Contains Duplicate

**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/duplicate-integer/question?list=blind75)

Given an integer array `nums`, return `true` if any value appears **more than once** in the array, otherwise return `false`.

## Example 1:

```text
Input: nums = [1, 2, 3, 3]

Output: true
```

## Example 2:

```text
Input: nums = [1, 2, 3, 4]

Output: false
```

## Constraints:

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
