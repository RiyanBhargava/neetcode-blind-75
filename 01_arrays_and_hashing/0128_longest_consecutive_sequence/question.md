# 128. Longest Consecutive Sequence

**Category:** Arrays & Hashing  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/longest-consecutive-sequence/) | [LeetCode problem](https://leetcode.com/problems/longest-consecutive-sequence/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given an unsorted integer array, return the length of its longest run of consecutive integer values. Values need not be adjacent in the input, and duplicates do not extend a run. Use O(n) time.

## Example

```text
nums = [9, 2, 4, 3, 3, 20] -> 3
```
