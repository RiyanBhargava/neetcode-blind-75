# 48. Rotate Image

**Category:** Math & Geometry  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/rotate-matrix/) | [LeetCode problem](https://leetcode.com/problems/rotate-image/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Rotate an n by n matrix 90 degrees clockwise in place. Modify the original matrix without allocating another n by n matrix.

## Example

```text
matrix = [[1, 2], [3, 4]] -> [[3, 1], [4, 2]]
```
