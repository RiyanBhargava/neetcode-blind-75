# 54. Spiral Matrix

**Category:** Math & Geometry  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/spiral-matrix/) | [LeetCode problem](https://leetcode.com/problems/spiral-matrix/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Return all elements of a rectangular matrix in clockwise spiral order, starting from its top-left corner. Include every cell exactly once.

## Example

```text
matrix = [[1, 2, 3], [4, 5, 6]] -> [1, 2, 3, 6, 5, 4]
```
