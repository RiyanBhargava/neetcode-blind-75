# 73. Set Matrix Zeroes

**Category:** Math & Geometry  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/set-zeroes-in-matrix/) | [LeetCode problem](https://leetcode.com/problems/set-matrix-zeroes/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

For every cell that is zero in the original matrix, set its entire row and column to zero. Modify the matrix in place. Zeros created during the operation do not trigger additional rows or columns. Follow-up: use constant extra space.

## Example

```text
matrix = [[1, 0, 3], [4, 5, 6]] -> [[0, 0, 0], [4, 0, 6]]
```
