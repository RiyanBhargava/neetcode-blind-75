## Problem brief

Given an integer array and a target, return the indices of two distinct elements whose values add up to the target. Exactly one valid pair exists, and an element cannot be used twice.

## Example

`nums = [2, 7, 11, 15]`, `target = 9` → `[0, 1]`

## Constraints

`2 <= len(nums) <= 10^4`; values and target fit within signed 32-bit integers.
