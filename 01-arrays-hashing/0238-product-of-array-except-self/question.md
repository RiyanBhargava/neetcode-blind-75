## Problem brief

Return an array where each position contains the product of every input value except the value at that position. Solve without division and in linear time.

## Example

`nums = [1, 2, 3, 4]` → `[24, 12, 8, 6]`

## Constraints

`2 <= len(nums) <= 10^5`; every prefix or suffix product fits in a signed 32-bit integer.
