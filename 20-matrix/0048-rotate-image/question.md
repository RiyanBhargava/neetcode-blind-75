## Problem brief

Rotate an `n × n` matrix 90 degrees clockwise in place without allocating another matrix for the result.

## Example

`[[1,2],[3,4]]` → `[[3,1],[4,2]]`

## Constraints

`1 <= n <= 20`; the matrix is square.
