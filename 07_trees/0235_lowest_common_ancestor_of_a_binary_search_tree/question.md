# 235. Lowest Common Ancestor of a Binary Search Tree

**Category:** Trees  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/lowest-common-ancestor-in-binary-search-tree/) | [LeetCode problem](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-search-tree/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

In a binary search tree with distinct values, find the lowest common ancestor of two given nodes that both exist in the tree. A node may be its own ancestor. Return the ancestor node.

## Example

```text
root = [6, 2, 8, 0, 4, 7, 9], p = 2, q = 4 -> node 2
```
