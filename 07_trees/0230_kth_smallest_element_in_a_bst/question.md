# 230. Kth Smallest Element In a Bst

**Category:** Trees  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/kth-smallest-integer-in-bst/) | [LeetCode problem](https://leetcode.com/problems/kth-smallest-element-in-a-bst/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given a binary search tree and a valid one-based rank k, return its kth smallest node value. Follow-up: consider how to support frequent rank queries when the tree changes.

## Example

```text
root = [4, 2, 6, 1, 3], k = 3 -> 3
```
