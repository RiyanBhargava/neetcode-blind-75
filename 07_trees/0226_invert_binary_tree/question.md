# 226. Invert Binary Tree

**Category:** Trees  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/invert-a-binary-tree/) | [LeetCode problem](https://leetcode.com/problems/invert-binary-tree/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Invert a binary tree by swapping the left and right children at every node. Return its root; an empty tree stays empty.

## Example

```text
root = [2, 1, 4] -> [2, 4, 1]
```
