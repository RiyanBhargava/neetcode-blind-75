# 102. Binary Tree Level Order Traversal

**Category:** Trees  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/level-order-traversal-of-binary-tree/) | [LeetCode problem](https://leetcode.com/problems/binary-tree-level-order-traversal/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Return the node values of a binary tree grouped by depth, from the root downward. Within each level, list nodes from left to right. An empty tree produces an empty list.

## Example

```text
root = [5, 2, 8, null, 3] -> [[5], [2, 8], [3]]
```
