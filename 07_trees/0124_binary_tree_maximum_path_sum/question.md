# 124. Binary Tree Maximum Path Sum

**Category:** Trees  
**Difficulty:** Hard

[NeetCode problem](https://neetcode.io/problems/binary-tree-maximum-path-sum/) | [LeetCode problem](https://leetcode.com/problems/binary-tree-maximum-path-sum/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Return the greatest sum along any nonempty path in a binary tree. A path follows parent-child edges without repeating a node, may start and end anywhere, and need not include the root.

## Example

```text
root = [-5, 4, 6] -> 6
```
