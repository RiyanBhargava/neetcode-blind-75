# 104. Maximum Depth of Binary Tree

**Category:** Trees  
**Difficulty:** Easy

## Task

Return the maximum number of nodes on a path from the root of a binary tree to a leaf. Return zero for an empty tree.

## Example

```text
root = [5, 2, 8, null, 3] -> 3
```
