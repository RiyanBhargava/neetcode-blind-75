# 98. Validate Binary Search Tree

**Category:** Trees  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/valid-binary-search-tree/) | [LeetCode problem](https://leetcode.com/problems/validate-binary-search-tree/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Determine whether a binary tree is a valid binary search tree: every value in a node's left subtree must be strictly smaller, and every value in its right subtree strictly larger. This rule must hold at every node.

## Example

```text
root = [5, 3, 7, null, null, 4, 8] -> false
```
