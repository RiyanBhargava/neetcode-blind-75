# 572. Subtree of Another Tree

**Category:** Trees  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/subtree-of-a-binary-tree/) | [LeetCode problem](https://leetcode.com/problems/subtree-of-another-tree/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given two nonempty binary trees root and subRoot, determine whether some node in root starts a subtree identical to subRoot in both structure and values. A subtree includes all descendants of its root.

## Example

```text
root = [4, 2, 7, 1, 3], subRoot = [2, 1, 3] -> true
```
