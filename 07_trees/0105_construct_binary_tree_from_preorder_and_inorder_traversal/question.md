# 105. Construct Binary Tree From Preorder And Inorder Traversal

**Category:** Trees  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/binary-tree-from-preorder-and-inorder-traversal/) | [LeetCode problem](https://leetcode.com/problems/construct-binary-tree-from-preorder-and-inorder-traversal/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Reconstruct a binary tree from its preorder and inorder traversal arrays and return the root. All values are distinct, and the two traversals describe the same tree.

## Example

```text
preorder = [2, 1, 3], inorder = [1, 2, 3] -> [2, 1, 3]
```
