# 295. Find Median From Data Stream

**Category:** Heap / Priority Queue  
**Difficulty:** Hard

[NeetCode problem](https://neetcode.io/problems/find-median-in-a-data-stream/) | [LeetCode problem](https://leetcode.com/problems/find-median-from-data-stream/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Design MedianFinder with addNum(num) to insert an integer and findMedian() to return the median of all inserted values. With an even number of values, return the average of the two middle values. Median queries occur only after an insertion.

## Example

```text
addNum(8), addNum(2), findMedian() -> 5.0; addNum(3), findMedian() -> 3.0
```
