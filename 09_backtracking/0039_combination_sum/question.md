# 39. Combination Sum

**Category:** Backtracking  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/combination-target-sum/) | [LeetCode problem](https://leetcode.com/problems/combination-sum/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given distinct positive candidates and a positive target, return every unique combination that sums to target. A candidate may be reused any number of times. Combination order and the order of values within a combination do not matter.

## Example

```text
candidates = [2, 5, 7], target = 7 -> [[2, 5], [7]]
```
