# 33. Search In Rotated Sorted Array

**Category:** Binary Search  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/find-target-in-rotated-sorted-array/) | [LeetCode problem](https://leetcode.com/problems/search-in-rotated-sorted-array/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

An increasing array of distinct integers has been rotated. Return the index of target, or -1 if it is absent. Use O(log n) time.

## Example

```text
nums = [6, 8, 1, 3, 4], target = 3 -> 3
```
