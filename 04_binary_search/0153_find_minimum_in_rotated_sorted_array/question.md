# 153. Find Minimum In Rotated Sorted Array

**Category:** Binary Search  
**Difficulty:** Medium

## Task

A nonempty array of distinct integers was sorted in increasing order and then rotated. Return its minimum value using O(log n) time.

## Example

```text
nums = [6, 8, 1, 3, 4] -> 1
```
