# 435. Non Overlapping Intervals

**Category:** Intervals  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/non-overlapping-intervals/) | [LeetCode problem](https://leetcode.com/problems/non-overlapping-intervals/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given intervals, return the minimum number that must be removed so the remaining intervals do not overlap. Touching at an endpoint is allowed in this problem.

## Example

```text
intervals = [[1, 3], [2, 4], [3, 5]] -> 1
```
