# 56. Merge Intervals

**Category:** Intervals  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/merge-intervals/) | [LeetCode problem](https://leetcode.com/problems/merge-intervals/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given closed intervals in any order, merge all overlapping intervals and return the resulting non-overlapping intervals. Intervals sharing an endpoint overlap.

## Example

```text
intervals = [[5, 7], [1, 3], [2, 6]] -> [[1, 7]]
```
