# 57. Insert Interval

**Category:** Intervals  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/insert-new-interval/) | [LeetCode problem](https://leetcode.com/problems/insert-interval/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given non-overlapping closed intervals sorted by start, insert one new closed interval and merge any overlaps. Return the resulting non-overlapping intervals sorted by start. Intervals that share an endpoint overlap.

## Example

```text
intervals = [[1, 2], [5, 7]], newInterval = [2, 6] -> [[1, 7]]
```
