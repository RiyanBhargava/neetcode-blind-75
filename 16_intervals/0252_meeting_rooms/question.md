# 252. Meeting Rooms

**Category:** Intervals  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/meeting-schedule/) | [LeetCode problem](https://leetcode.com/problems/meeting-rooms/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given meeting start and end times, determine whether one person can attend every meeting. A meeting ending exactly when another begins does not conflict. Input intervals need not be sorted.

## Example

```text
intervals = [[1, 3], [3, 5], [6, 8]] -> true
```
