# 322. Coin Change

**Category:** 1-D Dynamic Programming  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/coin-change/) | [LeetCode problem](https://leetcode.com/problems/coin-change/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given positive coin denominations and a nonnegative amount, return the fewest coins needed to make that amount exactly. You have an unlimited supply of each denomination. Return -1 if it cannot be made, and zero for amount zero.

## Example

```text
coins = [2, 5], amount = 11 -> 4
```
