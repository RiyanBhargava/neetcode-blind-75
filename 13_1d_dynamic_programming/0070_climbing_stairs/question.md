# 70. Climbing Stairs

**Category:** 1-D Dynamic Programming  
**Difficulty:** Easy

[NeetCode problem](https://neetcode.io/problems/climbing-stairs/) | [LeetCode problem](https://leetcode.com/problems/climbing-stairs/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

A staircase has n steps. Each move climbs either one or two steps. Return the number of distinct sequences of moves that reach the top exactly.

## Example

```text
n = 4 -> 5
```
