# 213. House Robber II

**Category:** 1-D Dynamic Programming  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/house-robber-ii/) | [LeetCode problem](https://leetcode.com/problems/house-robber-ii/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Each element gives the money in a house arranged in a circle, so the first and last houses are neighbors. Return the maximum total obtainable without taking from adjacent houses. A single house can be taken.

## Example

```text
nums = [4, 1, 2, 7] -> 8
```
