# 5. Longest Palindromic Substring

**Category:** 1-D Dynamic Programming  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/longest-palindromic-substring/) | [LeetCode problem](https://leetcode.com/problems/longest-palindromic-substring/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Return a longest contiguous palindromic substring of a nonempty string. A palindrome reads the same in both directions. If several substrings tie for maximum length, any one is acceptable.

## Example

```text
s = "cabbad" -> "abba"
```
