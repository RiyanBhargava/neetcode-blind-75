# 91. Decode Ways

**Category:** 1-D Dynamic Programming  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/decode-ways/) | [LeetCode problem](https://leetcode.com/problems/decode-ways/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Digits encode letters using 1 for A through 26 for Z. Return the number of ways to decode a nonempty digit string completely. A code cannot have a leading zero, and zero cannot be decoded alone; return zero when no decoding exists.

## Example

```text
s = "12" -> 2; s = "06" -> 0
```
