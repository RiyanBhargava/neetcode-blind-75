# 152. Maximum Product Subarray

**Category:** 1-D Dynamic Programming  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/maximum-product-subarray/) | [LeetCode problem](https://leetcode.com/problems/maximum-product-subarray/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Given a nonempty integer array, return the largest product of any nonempty contiguous subarray. Values may be positive, negative, or zero. The answer fits in a signed 32-bit integer.

## Example

```text
nums = [-2, 3, -4] -> 24
```
