# 647. Palindromic Substrings

**Category:** 1-D Dynamic Programming  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/palindromic-substrings/) | [LeetCode problem](https://leetcode.com/problems/palindromic-substrings/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Count all contiguous substrings that are palindromes. Substrings at different index ranges count separately even if their text is identical. Every single character is a palindrome.

## Example

```text
s = "aaa" -> 6
```
