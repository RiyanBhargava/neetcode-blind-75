# 139. Word Break

**Category:** 1-D Dynamic Programming  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/word-break/) | [LeetCode problem](https://leetcode.com/problems/word-break/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Determine whether a string can be split completely into one or more words from a dictionary. Dictionary words may be reused, and every chosen piece must be a contiguous segment.

## Example

```text
s = "applepenapple", wordDict = ["apple", "pen"] -> true
```
