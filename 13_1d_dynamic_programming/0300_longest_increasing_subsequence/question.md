# 300. Longest Increasing Subsequence

**Category:** 1-D Dynamic Programming  
**Difficulty:** Medium

[NeetCode problem](https://neetcode.io/problems/longest-increasing-subsequence/) | [LeetCode problem](https://leetcode.com/problems/longest-increasing-subsequence/) | [Blind 75 list](https://neetcode.io/practice/practice/blind75)

## Task

Return the length of the longest strictly increasing subsequence of an integer array. A subsequence preserves relative order but may skip elements. Follow-up: achieve O(n log n) time.

## Example

```text
nums = [4, 1, 3, 2, 5] -> 3
```
